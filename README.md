# Flavor Lens - flavorlenstest1

Modernized Next.js version of the Flavor Lens landing page, prepared for Cloudflare deployment.

## Cloudflare Deployment
This project uses the `@opennextjs/cloudflare` adapter.

### Build and Deploy
- **Build**: `npm run build:cloudflare`
- **Deploy**: `npm run deploy:cloudflare`

### Cloudflare Dashboard Settings
- **Build command**: `npm run build:cloudflare`
- **Deploy command**: `npm run deploy:cloudflare`
- **Build output directory**: (Leave as default, the adapter handles this)

## Local Development
```bash
npm install
npm run dev
```
